How it works

Three steps, and nothing hidden

01

Start a chat, add PDFs

Each chat holds its own documents: annual reports, board packs, contracts. A chat only ever searches the files you put in it.

02

Ask in plain language

The agent decides whether it needs to search. When it does, it queries by meaning and by keyword at once, then a local reranker keeps the best five passages.

03

Check the source

Every claim carries a page reference. Hover it and the original text appears, exactly as it sits in the PDF.

It will tell you what the filing says, not what to do about it

Ask for a recommendation and Vouch declines, then shows the figures the documents actually report. The judgement stays with you.

—No answer without a citation
—Scans that cannot be read are flagged, not silently skipped
—Retrieval steps stay visible while the agent works
